# Libertas Matter Constants

Auto-generated Rust constants for the Libertas Matter data model. Attribute,
command, and event modules also expose `ALL` catalogs generated by
`libertas-matter-macros`.
The exported `matter_definitions!` macro materializes owned, typed TLV
definitions inside the `libertas-matter` runtime without introducing a crate cycle.

Regenerate this package from the LibMatter schema generator. Do not edit generated files by hand.
